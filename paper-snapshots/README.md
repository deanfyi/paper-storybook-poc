# Paper export snapshots

Raw `get_jsx` output of every source board in the Paper file, one file per board, rewritten by
each `paper-to-code` sync. `git diff paper-snapshots` = what changed in Paper since the last sync
(and, in a PR, what the designer changed). Not code: never imported, never formatted.
Created on the first sync (see `.claude/skills/paper-to-code/SKILL.md`, step 0).
